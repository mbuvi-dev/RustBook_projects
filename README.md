# 🦀 Learning Rust: One Project at a Time

Welcome to my Rust learning journey!

I've been working through **The Rust Programming Language (the official Rust Book)**, building projects, organizing my code into folders, and writing notes as I go. This repository is where I'll push everything I build, break, fix, and learn along the way.

**The mission? Prove to myself that we can all tackle Rust.** 💪

Funny thing is, lately, my motivation to code has been moving like it's serving a notice period. 😂 Instead of waiting for motivation to magically return, I'm using this repo to get back into the habit, stay consistent, and challenge myself to learn something new.

### Why Rust?

I've been noticing more companies adopting Rust, and I want to understand why. Rather than just following the trend, I want to get my hands dirty and discover what makes Rust different:

- 🦀 Ownership, borrowing, and memory safety.
- ⚡ Performance without relying on a garbage collector.
- 🛠️ A powerful type system and compiler that actually makes you think.
- 🌍 Why Rust is gaining attention in systems programming, infrastructure, and beyond.

### What's inside?

- Projects and exercises from the official Rust Book.
- Experiments, mistakes, debugging sessions, and solutions.
- Notes explaining concepts in my own words.
- Lessons learned as I progress from beginner to building more meaningful projects.

I'm not here to pretend I know Rust already. I'm here to learn it properly, one compiler error at a time.

**The goal to feel and be an expert, to become one.**

If you're also learning Rust, feel free to follow along. Let's figure this language out together.

**To my-self future crab master we good.**
